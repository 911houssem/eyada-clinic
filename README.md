# عيادة — نظام إدارة العيادات

## ✨ المميزات

- **الحجز العام للمريض**: صفحة مستقلة لكل عيادة عبر رابط مخصص، مع **تخصيص الوقت تلقائياً** لأقرب موعد متاح (تسلسل المواعيد) ومنع الحجز المكرر لنفس الرقم في اليوم نفسه.
- **المواعيد**: جدول يومي/أسبوعي، إنشاء وتعديل المواعيد، حساب وقت الانتهاء حسب مدة الخدمة، وكشف التعارض.
- **الخدمات والأسعار**: تحديد **المدة (1–10000 دقيقة)** والسعر لكل خدمة، وتظهر مباشرة للمريض في صفحة الحجز.
- **المرضى والسجلات الطبية**: ملف كامل لكل مريض مع التاريخ الطبي والملفات.
- **المالية**: فواتير، ديون، بيع منتجات، وتقارير.
- **المخزون**: إدارة الأصناف والكميات وحدود إعادة الطلب.
- **الفريق والصلاحيات**: أدوار (مالك / مدير / طبيب / استقبال) مع تحكم دقيق بالصلاحيات.
- **تعدد العيادات**: إدارة عدة فروع، ولكل عيادة رابط حجز مستقل.
- **الاشتراكات والعروض**: خطط اشتراك، فترات تجريبية، وعروض/خصومات.
- **الأمان**: تغيير كلمة المرور، رمز التحقق بخطوتين (2FA)، وإنهاء الجلسات.

## 🧱 التقنية

| الجزء | الوصف |
|------|-------|
| الخادم | `server.js` — Node.js بدون مكتبات، تخزين على `data/db.json` بكتابة ذرّية |
| الواجهة | `index.html` + حزمة عميل Next.js جاهزة تحت `_next/` |
| صفحة الحجز | `booking-page.js` — ملف واحد مستقل (HTML/CSS/JS بدون خطوة بناء) |

## 🚀 التشغيل

```bash
node server.js
```

ثم افتح: <http://127.0.0.1:3000>

- لخيارات المنفذ: `node server.js --port 3001` أو `node server.js --auto-port`.
- عند أول تشغيل يُنشئ الخادم قاعدة بيانات تجريبية تلقائياً (ملف `data/db.json` غير مُضمّن في المستودع).

### حسابات التجربة

| الدور | اسم المستخدم | كلمة المرور |
|------|-------------|-------------|
| المالك (super_admin) | `admin` | `admin123` |
| طبيب | `doctor` | `doctor123` |
| استقبال | `reception` | `reception123` |

## 🌐 صفحة الحجز

مثال: <http://127.0.0.1:3000/booking/al-noor-clinic>

## 📂 البنية

```
server.js            الخادم + واجهات API + تقديم الملفات الثابتة
booking-page.js      مُنشئ صفحة الحجز العامة المستقلة
index.html           هيكل عميل لوحة التحكم
_next/               ملفات الواجهة المبنية (JS/CSS/الخطوط)
tools/               أدوات واختبارات مساعدة
docs/                الشرح + صور الشاشات
data/                قاعدة البيانات (تُنشأ تلقائياً، غير مُضمّنة)
```
